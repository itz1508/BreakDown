# PROJECT RECORD INDEX

| Log | Responsibility | Format |
|---|---|---|
| log/CHANGE.LOG | Architecture and design changes; OLD path → FIXED path | JSONL |
| log/BUILT.LOG | Actual files and folders built or modified | JSONL |
| log/LEARNING.LOG | Step-by-step processing experience and lessons | JSONL |
| log/MEM.LOG | User decisions, agent suggestions, and conclusions | Markdown |

## Lifecycle

LEARNING → CHANGE → BUILT → MEM

## Rules

- CHANGE records design intent and structural changes.
- BUILT records actual filesystem output and validation.
- LEARNING preserves successful and unsuccessful processing.
- MEM preserves concise, confirmed project knowledge.
- MEM promotion requires deliberate selection.
